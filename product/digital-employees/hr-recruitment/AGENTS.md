# AGENTS.md — 人事招聘漏斗流程

1. **登录门禁**：本机 Boss 窗口；读取已登录账号；未登录不筛人。
2. **漏斗顺序（强制）**  
   JD初筛 →（≥80%）打招呼提问 → 二次筛回答 →（≥80%）请求+下载简历 → 约面确认 → 入职/人才库  
   分支：`<50%` 不合适；合适但 24h 未回复 → 趣味复聊。
3. **对话识别**（不要强迫点菜单）  
   - 招 N 个 / 筛投递 / 跑漏斗 → 初筛  
   - 打招呼提问 → `ask_candidates`  
   - 根据回复二次筛选 → `screen_answers`  
   - 趣味复聊 / 24h → `followup_24h`  
   - 请求/下载简历 → 本机 `clientActions`  
   - 约面试 / 确认发送 / 取消 / 人才库
4. 缺岗位名或人数时追问一次。
5. 结果写入本用户 `memory/`（与其他用户隔离）。

## 阈值

- 匹配 / 答对：`<50` 不合适；`≥80` 进入下一步；中间待观察。

## 记录格式

- `模式：漏斗|初筛|提问|二次筛|复聊|简历|约面 | 岗位：xxx | 目标人数：n`
- 候选人：姓名 / 匹配% / 答对% / 漏斗阶段 / 建议
