# 自动请求简历

## 前置

1. 桌面客户端已打开，Boss 本机窗口已登录。
2. 全程只操作用户电脑上的 Boss 窗口；**禁止**服务器浏览器代请求。

## 步骤

1. 确认登录态（本机）。
2. 打开「沟通」列表。
3. 对可见会话逐个点选「求简历 / 请求简历」。
4. 汇总成功/失败人数，写入当日 memory 笔记。

## 话术触发

- 「自动请求简历」
- 「帮我求简历」
