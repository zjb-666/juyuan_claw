# 人事招聘 · Boss 直聘实网验收清单

日期：2026-07-31  
范围：桌面客户端 **聚元灵创 ≥ 0.1.7** + 产品 BFF + 本机 Boss 窗口  
前提：文字漏斗演示已通过；本清单验证**真实操控 Boss**，不是演示种子数据。

## 0. 环境切换（必做）

| 项 | 演示（当前） | 实网 |
|---|---|---|
| `DEMO_HR_PIPELINE` | `1` | **`0`（关闭）** |
| 客户端 | 浏览器黄条 UI | **桌面安装包 / `electron .`** |
| Boss | 可不登录 | **本机窗口已登录「沟通」** |
| BFF | `8787` | 同；`PRODUCT_PUBLIC_URL` 指向可达地址 |
| Gateway | 可选 | 口语混合识别建议启动 `18789` |

改完 `.env` 后**重启 BFF**。桌面端改代码后需重打/重开 Electron。

```bash
# BFF（示例）
cd product/backend
PRODUCT_ENV_PATH=../.env DEMO_HR_PIPELINE=0 DIGITAL_EMPLOYEE_DEV_GRANT=hr-recruitment HR_INTENT_LLM=1 node src/server.js
```

## 1. 安装与启动

- [ ] 安装或运行桌面包 **0.1.7+**（含 `boss-actions.js` / `check-inbox-replies` IPC）
  - Windows：解压 `product/desktop/dist/聚元灵创-0.1.7-Windows.zip`，运行其中的 `聚元灵创.exe`
  - Linux：`product/desktop/dist/聚元灵创-0.1.7.AppImage`
- [ ] 登录产品账号，进入「人事招聘数字员工」
- [ ] **不应**再出现「请用桌面客户端…」黄条（若出现 = 仍在浏览器里打开）
- [ ] 首次自动化弹出同意书 → 同意本机 Boss 窗口权限

本地开发可先：

```bash
cd product/desktop
npm start
```

## 2. Boss 登录门禁

- [ ] 对话或按钮：「打开 Boss 窗口」→ 本机出现 zhipin 窗口
- [ ] 人工完成登录（不代填短信）
- [ ] 「检验登录态」→ 成功（未登录/风控应明确失败文案）
- [ ] 确认窗口在 **沟通** 列表页（`/web/chat/`）

## 3. 漏斗实操（按顺序勾）

用**真实沟通列表里的候选人姓名**（不要指望演示里的「张同学」一定存在）。

| # | 操作话术 / 动作 | 期望本机行为 | 通过 |
|---|---|---|---|
| 1 | `招 N 个某某岗位` / 筛今日投递 | 不再只吐演示三人；应来自 Boss 侧数据或明确「未拉到」 | [ ] |
| 2 | `问张某：……`（换成真实名） | Boss 对应会话被打开并**发出**消息 | [ ] |
| 3 | `有谁回复了` / `某某回复了` | 本机打开会话读摘要；有链接/媒体则提示人事目视 | [ ] |
| 4 | `根据回复二次筛选` | 名单+机器分；多媒体不自动放行 | [ ] |
| 5 | 达标后请求/下载简历 | 本机点到「求简历/下载简历」类按钮 | [ ] |
| 6 | `只约某某，周五下午3点，线下，地点：前进国际12楼` | 出草稿且地点/时间齐全 | [ ] |
| 7 | `确认发送` | **本机代发邀约文案**到对应沟通会话（非仅 DB 标记） | [ ] |

## 4. 失败与风控

- [ ] 未登录时自动操作 → 提示去登录，不静默成功
- [ ] IP 风控/403 → 明确「访问受限」，不伪造已发送
- [ ] 沟通列表无名匹配 → 说明未找到会话，不报假成功

## 5. 已知限制（验收时知情）

1. **0.1.8+**：说「招 N 个岗位」会触发本机 `scrape_inbox` 从「沟通」拉真实候选人再 JD 初筛；旧桌面端无此 IPC 会提示升级。沟通列表为空则无法初筛。  
2. DOM 按**可见文案**点选；Boss 改版可能导致点不中 → 记失败截图与页面文案。  
3. 演示种子仅在 `DEMO_HR_PIPELINE=1` 出现；实网验收必须为 `0`。
